# отбой_

Лёгкий веб-чат с **DeepSeek** в одном HTML-файле. Без сервера, без сборки, без зависимостей.
Работает с телефона через обычный браузер, хостится бесплатно на GitHub Pages.

![Мобильная версия](screens.jpg)

## Зачем
Хотелось быстрый личный чат с нейронкой, который:
- открывается с любого телефона по ссылке, без установки приложений и без VPN;
- не требует своего сервера (браузер ходит прямо в `api.deepseek.com`);
- не хранит ключ в открытом виде;
- не даёт случайно потратить больше, чем задумано.

## Возможности
- **Стриминг ответов**, markdown, блоки кода с кнопкой «копировать», таблицы.
- **Модели** `deepseek-flash` (V4.1 Flash) и `deepseek-v4-pro`, переключение одним тапом.
- **Режим размышлений** (thinking): вкл/выкл, по умолчанию выключен (так дешевле).
- **Шифрование**: API-ключ, чаты и настройки хранятся в `localStorage` только в зашифрованном виде
  (AES-GCM 256, ключ получается из PIN через PBKDF2-SHA256, 250 000 итераций).
- **Автоблокировка** при бездействии или уходе вкладки в фон; после 10 неверных PIN всё стирается.
- **Бюджет на месяц**: подсчёт расходов с учётом пиковых и ночных цен DeepSeek; при превышении запросы блокируются.
- **Баланс API** в настройках.
- Кнопка **«Стереть всё с устройства»**.
- Тёмная и светлая темы, адаптивная вёрстка, можно добавить на домашний экран как приложение.

## Как пользоваться
1. Получи ключ на [platform.deepseek.com](https://platform.deepseek.com) (API keys) и пополни баланс.
2. Открой сайт, вставь ключ, придумай PIN.
3. Пиши.

Ключ уходит только на `api.deepseek.com`. У автора сайта его нет: это статическая страница, код открыт.

## Развернуть свою копию (5 минут, без git)
1. Сделай **Fork** этого репозитория (или создай новый репозиторий и загрузи файлы через *Add file → Upload files*).
2. *Settings → Pages → Build and deployment*: Source **Deploy from a branch**, Branch **main**, папка **/(root)** → Save.
3. Через минуту сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

Локально: `python -m http.server` в папке проекта и открыть `http://localhost:8000`.
Просто двойной клик по `index.html` не подойдёт: шифрованию нужен HTTPS или localhost.

## Безопасность, честно
- Шифрование защищает от того, кто возьмёт телефон и полезет в данные браузера. От вредоносного
  расширения или заражённого устройства оно не защитит.
- PIN из 4 цифр перебирается офлайн, если кто-то скопирует данные браузера. Бери PIN длиннее (6–12 цифр).
- **Никогда не коммить свой API-ключ** в репозиторий. Сайт он не требует и в коде его нет.
- Поставь месячный лимит и на стороне DeepSeek, и в настройках сайта.
